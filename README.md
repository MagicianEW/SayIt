# SayIt （说吧）

> 本地桌面文本转语音（TTS）工具，支持多语种、多音色

## 功能特点

- **多语种支持**：支持 37+ 种语言，包括中文（简体/粤语/台语）、英语、日语、韩语等
- **多音色选择**：多种音色可选，支持按语种和性别筛选
- **参数可调**：可调节语速、音高、音量
- **逐句播放**：文本分句播放，音频拼接无损
- **导出功能**：支持导出 MP3 格式音频
- **设定导入导出**：可保存和恢复音色、语速等偏好设置
